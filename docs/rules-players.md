# ドットサッカー：選手・ガチャ・対戦のルール（2026-10-08 決定）

## 選手の正体（一生変わらない）
- 顔・名前・タイプ・ポジション・固有スキルは、その選手だけのもの。変えない
- CPUチームの最初の25人は rosters.js で固定（誰が始めても同じ）。rosters.js は作り直さない
- CPUの選手は年をとらない・引退しない（ガチャと対戦で、誰の世界でも同じ顔ぶれにするため）。成長・引退の仕組みは career.js に残してあるが LIFE_ON = false で止めている
- 国内屈指は、最初の持ち主と自分の選手だけで比べる（CPUの能力は変わらないので、CPU同士では入れ替わらない）

## 顔
- 専用の顔：国内屈指18人・エース・中心選手（計158人）。後継者はいないので、これで全部
- 専用の顔は使い回さない。モブは共有の顔を、髪・肌・ユニフォームの色を塗り替えて使う
- 顔の格（オーラ）は選手の格（素質）に合わせる。強い選手ほど目つき・表情で強さが伝わる顔
- 顔はGPTで作る（依頼表：face-prompts.html、対応表：tools/face_plan.json）

## NFT
- やらない

## ガチャ移籍
- スター選手はガチャで手に入る（お金で回すガチャ）
- 手に入れると「実質の移籍」：その選手は元のチームからいなくなり、代わりに自分の選手を1人出す（トレード）
- 出した自分の選手は、そのチームに合った強さになって、CPUチームで試合に出る
- 来た選手の能力はE〜Dから。固有スキルを持ってくる → 弱いけど育てると化ける
- 同じ選手を2回目以降に引くと「凸」：固有スキルの発動しやすさと効果が上がる＋カード枠の色が変わる
  （能力の上限は上げない＝お金で能力の強さは買えない）

## 課金まわり（リリース前に専門家に確認すること）
- アプリストアで出す
- ガチャの確率表示、コンプガチャ禁止、未成年の課金上限、ゲーム内通貨を売るなら資金決済法

## 対戦
- サーバーは Supabase（ログイン・選手データ・対戦記録。ズル防止のため選手データはサーバー側で持つ）
- ① 登録チームとの自動対戦（「試合をする」→ 実在のほかの人の登録チームと自動で戦う。ランク付き）
- ② 友達とのリアルタイム対戦（同じ試合シードで2人同時に再生し、交代・作戦だけをリアルタイムで送り合う）

## 試合の判断（共通）
- 前後半の終わりの笛：攻撃の最中（シュートのこぼれ球を含む）は、その攻撃が終わるまで吹かない。終わるのは、相手に取られた・GKが持った・プレーが切れた・ゴール・攻めている側が自陣へ下げた時（最大20秒・版433〜）
- ストライカー（ストライカータイプのFW・国内屈指の点取り屋）は、いつも最終ラインぎりぎり・ゴール前の真ん中で決めるボールを待つ。パスを出したら、すぐゴール前へ走り込む（最後は自分が決めに行く・版440〜）
- 偽9番・ストライカーのFWは、守備をほぼしない。守備の時も相手のDFライン（いちばん近いCBのすぐ手前・オフサイドにならない所）に残る。寄せに行かない。こぼれ球を追うのは相手陣内だけ（版442〜）。攻撃の時は逆に、DFを振り切ってゴール前の空いた所（マークのいない所・持っている味方からのコースが空いている所）へ入り、オフサイドにならないぎりぎりでパスを待つ。だれがボールを持っていても同じ。オフサイドラインはボールの位置も含めて正しく見る（ボールより後ろならオフサイドにならないので、味方が運んだらその分だけ前へ出る）（版447〜）
- アンカーのMFは、攻撃の時も上がらず、自分のCBの少し前（DFラインの約9m前・守備の時は約5.5m前、真ん中寄り）にいる。寄せに行くのは、ボールが9m以内で自分の前にある時だけ（版443〜）
- GK（版458）：①1対1（前に味方がいない相手が13m以内）では前へ詰めて角度を消す（ふつうの場面の前に出る距離は変えない。前に出すぎると失点が増えたため）。②枠に来るシュートにだけ飛ぶ（外れるボールには飛ばない）。回転で曲がる分も読む。ポストの外まで飛び出さない。③キャッチした後は、フリーの味方がいればまずつなぐ（9割）。少し寄せられていてもコースが空いていれば近くの味方へ。蹴る時は、競り合いになるFWの頭ではなく、空いていて味方が近くにいる所へ。④横っ跳びは手で描いた8方向の絵（跳んだ向きへ体ごと伸びて飛び込み、両手を伸ばしたまま倒れ込む）
- シャドーのMF（チームに1人だけ。固有スキル持ち＞足の速い順。ほかのシャドーはふだんどおり守備にも戻る：版445）は、いつもチームの点取り屋（FW）の近くにいる。攻撃の時はFWの6〜8m後ろ、守備の時もハーフライン付近より下がらずに前に残る。どのチームも、相手ゴールから約40m以内では点取り屋（エースFW＝紅蓮の牙 ＞ ストライカー ＞ キックの高いFW）へのパスを選びやすい（版444〜）
- 足もとに収める時、ボールは転がって寄る（一瞬で足もとへ飛ばない・版432〜）
- PKマークより前（約13m以内）で、シュートコースに相手がいない時は、迷わず打つ（版429〜）
- 「相手に触られにくい」パス（固有スキルなど）は、相手が足を出して取れなかった時、はじいてこぼさずにそのまま抜けていく（版430〜）
- サイド（PAの横・ゴールライン寄り）でボールを持ったら、角度のない所からは打たない。第一の選択は、ゴール前に入ってくる味方へのクロス（ヘディング・ボレーに合わせる）か、近くなら低い折り返し（版426〜）

## 対策役（裏への抜け出し・指揮者の1本への対策）

- ラインコントローラー：走り出しを読む（判断・メンタル vs パスの出し手の判断）。ラインの近くから走り出した相手には、一斉に押し上げて置き去り（本当のオフサイド）。深い所から走り出した相手には、一斉にラインを下げて裏のスペースを消す（カバーのDFが触りやすい）。桜島の号令は、読みやすく・大きく動く。

- マークの受け渡し：相手が走り出したら、近くのDFがついていく（タイプ・判断・守備で決まる）。ついていったDFは、抜け出した相手にも寄せられる。スイーパー（雅の後始末）は裏のスペースの後ろへ先回りしてカバー。

## 版514（2026-10-13）ポテンシャルを廃止して「調子」に
- 理由：ポテンシャルは下がり続けるので、ベテランが育てられなくなる。調子は上下にゆらぐだけで、ずっと下がり続けることはない。
- 調子は5段階（矢印）：絶好調↑・好調↗・普通→・不調↘・絶不調↓。
- 毎週40%の確率で1段動く（良い時は下がりやすく、悪い時は上がりやすい＝普通に戻りやすい）。長い目で見た割合は 絶好調12%・好調23%・普通30%・不調22%・絶不調12%。
- 特訓の効き：絶不調0.6倍・不調0.8倍・普通1.0倍・好調1.2倍・絶好調1.4倍（疲労の倍率とかけ算）。
- 好調10%・絶好調20%で、試合に出なくても能力のどれか1つが少し伸びる（旧：ポテンシャル6以上）。
- ケガをすると調子が1段下がる（旧：ポテンシャルが下がる）。マッサージ等のカードで1段上がるのは今まで通り。
- 試合の能力補正（調子による小さな上下）は今まで通り。
- 表示：選手カードの「ポテンシャル」→「調子」、選手データ一覧の列も「調子」。スタメン画面の「調子」表示に矢印。
- 古いセーブはポテンシャルを消し、調子を5段階に丸める。

## 版558（2026-10-13）本家の試合の音に合わせた
